# 前端性能专项面：LCP 从 4.8s 优化到 2.1s 的完整答题模板

> 来源: 校友社区 (作者: 魏景初)
> 发布时间: 2026-04-12 21:37:25

## 面试信息
- **公司**: 星澜智联科技有限公司
- **岗位**: 前端工程师

## 面试流程
在线测评 -> 技术一面（基础） -> 技术二面（性能实战） -> 业务面

## 高频面试题
LCP 和 CLS 如何实战优化；代码分割边界怎么定；SSR 和 CSR 在该场景如何选；埋点如何验证优化收益

## 复盘建议
性能题别背概念，直接说“我如何拿数据定位问题”。建议随身准备一套常用指标口径（LCP/FID/INP/CLS）和一页优化 checklist，面试官会觉得你可立即上手。

## 详细记录
我这轮面试是现场给业务页面做性能诊断。先通过 Performance 面板定位是首屏资源阻塞和图片体积过大，再补充打包分析发现公共包过重。我的回答顺序是“先测量、再定位、后改造、最后验证”，分别给出 preload、按路由分包、图片格式升级和长任务拆分策略，并说明改完后 LCP、TTI 的变化。
