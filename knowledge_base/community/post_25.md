# 秋招后端四轮复盘：从接口性能到故障演练我踩过的坑

> 来源: 校友社区 (作者: 林书远)
> 发布时间: 2026-04-12 21:37:25

## 面试信息
- **公司**: 星澜智联科技有限公司
- **岗位**: Java后端工程师

## 面试流程
网申 -> 在线笔试（2道算法+2道系统题） -> 一面基础与项目 -> 二面系统设计 -> 三面故障处置与压测 -> HR终面

## 高频面试题
Redis 缓存一致性怎么保证；库存超卖如何兜底；慢 SQL 如何定位与治理；服务雪崩时限流、熔断和降级怎么组合；压测数据与线上差异怎么解释

## 复盘建议
建议准备 2 个能量化结果的项目故事，每个故事都要带“业务目标、技术方案、指标变化、失败教训”。回答系统设计题先给边界和核心指标，再给方案树，最后说明取舍。HR 面会看稳定性和协作，提前准备一次跨团队推进案例会很加分。

## 详细记录
这次面试最难的是二面和三面。二面要求我把简历里的“订单服务优化”讲成可复用方案，我给了背景流量、瓶颈 SQL、缓存命中率提升前后数据；三面现场追问线上故障处理，我按“发现-止损-定位-复盘”讲了 45 分钟，面试官重点看我有没有把风险隔离做在前面。最终拿到 offer，但能明显感受到只背八股完全不够，必须把项目里的指标和取舍讲透。
