# AI 工程师 - 大模型与 LLM 应用（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. 预训练、指令微调、对齐训练分别解决什么问题？
**解析：**
预训练解决模型有没有通识能力，指令微调解决模型会不会按要求做任务，对齐训练解决模型是否安全稳定可用。三者是分层目标：能力、行为、边界。若只堆叠数据不区分阶段，容易出现能聊但不好用、能答但不稳、能完成但不安全的问题。

### 2. 为什么 RAG 可以缓解幻觉但不能彻底消除？
**解析：**
RAG 将知识来源从模型参数扩展到外部文档，降低无依据生成概率。但其上限受限于检索链路质量：切片、嵌入、召回、重排任一环节失效都会污染上下文。即使检索正确，生成阶段仍可能过度推断，因此需要引用约束、拒答策略和结果审查。

### 3. Prompt 设计中最容易被忽略的工程要点是什么？
**解析：**
很多团队只写长提示词，却忽略版本治理。高质量 Prompt 体系应具备：模板化、参数化、版本号、A/B 对照、失败样本回放、灰度发布。Prompt 是产品资产，不是一次性文案。

### 4. Agent 系统为什么必须加工具权限控制？
**解析：**
Agent 一旦具备工具调用能力，就具备行动能力。如果权限模型不清晰，可能发生越权访问、错误执行、成本失控。通常需引入工具白名单、参数校验、执行确认和审计日志，形成最小权限闭环。

### 5. 大模型应用上线后，为什么要同时监控质量和成本？
**解析：**
只看质量会导致算力失控，只看成本会导致体验退化。线上应监控首字延迟、总时延、任务完成率、拒答率、幻觉率、平均 token 消耗、单位请求成本，并按用户分层做策略路由。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：RAG 系统中决定能否找到正确资料的核心环节是（ ）
A. 页面主题颜色  
B. 检索与重排策略  
C. 语音播放速度  
D. 前端组件数量

**参考答案：** B  
**答案解析：** 召回质量主要由向量检索与重排链路决定。若召回错误，再强的模型也难以输出可靠答案。

### 单选题 2：下列哪项最能直接降低大模型推理成本？（ ）
A. 增加系统提示词长度  
B. 请求分级路由到不同模型档位  
C. 固定使用最大模型  
D. 关闭缓存

**参考答案：** B  
**答案解析：** 分级路由可根据任务复杂度选择不同模型，通常能在质量可控前提下显著降本。

### 单选题 3：Agent 发生错误调用工具时，优先应补强（ ）
A. 页面动画  
B. 工具权限与参数校验层  
C. 字体样式  
D. 用户头像

**参考答案：** B  
**答案解析：** 工具调用错误通常属于执行安全与治理问题，应优先在权限和参数验证层兜底。

### 单选题 4：在生产环境中评估 Prompt 是否有效，最可靠方式是（ ）
A. 只看主观评价  
B. A/B 实验 + 任务指标  
C. 只看 token 数  
D. 只看日志量

**参考答案：** B  
**答案解析：** Prompt 优化必须量化验证，常见指标包括完成率、引用准确率、追问率、人工复核通过率等。

### 简答题 1：请描述一个企业级 RAG 的完整链路，并指出每一层风险。
**参考答案：**
可按七层设计：
1. 数据接入：风险在权限与时效性；  
2. 文档处理：风险在切片断义与冗余；  
3. 向量索引：风险在版本漂移与召回偏差；  
4. 检索重排：风险在漏召回与误召回；  
5. 生成回答：风险在幻觉与过度推断；  
6. 安全治理：风险在提示注入与敏感泄露；  
7. 监控评估：风险在只看离线指标忽略线上体验。

**答案解析：** 该题高分关键是系统思维 + 风险意识。只会讲模型原理但不讲治理，通常难拿高分。

### 简答题 2：如果线上对话质量下降，你会如何快速排查？
**参考答案：**
- 先看链路：是检索问题、生成问题还是工具执行问题；
- 再看数据：文档是否更新失败、索引是否陈旧；
- 再看策略：Prompt 是否变更、模型版本是否切换；
- 最后回放失败样本：定位共性并修复。

**答案解析：** 面试官看重排障顺序。优秀回答应体现先分层定位，再针对性修复的工程能力。
