# AI 工程师 - 深度学习与多模态（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. 为什么深度学习训练中需要学习率调度？
**解析：**
学习率决定参数更新步长。固定学习率在训练前期可能过小导致收敛慢，后期可能过大导致振荡。调度策略的核心是前快后稳：
- 预热阶段（Warmup）避免初始梯度不稳定；
- 主训练阶段用余弦退火或多段下降提高收敛效率；
- 后期小学习率帮助模型在最优值附近精细搜索。
工程上通常要和批大小、优化器、正则化一起调参，否则可能出现训练损失下降但验证集性能不上升。

### 2. BatchNorm、LayerNorm、RMSNorm 的差异是什么？
**解析：**
三者本质都是做特征归一化，但归一化维度不同：
- BatchNorm：按 batch 统计均值方差，CNN 中常见，对 batch size 敏感；
- LayerNorm：按特征维归一化，适合 Transformer，不依赖 batch 统计；
- RMSNorm：仅做均方根缩放，计算更轻，LLM 中常用于提高吞吐。
多卡训练中，BatchNorm 还涉及同步统计（SyncBN）问题，通信开销会影响训练速度。

### 3. 多模态模型中的对齐与融合分别解决什么问题？
**解析：**
- 对齐（Alignment）：解决不同模态语义空间不一致的问题，比如图像区域和文本词语如何对应；
- 融合（Fusion）：解决对齐后如何联合建模的问题，例如早融合、晚融合、跨注意力融合。
如果只做融合不做对齐，模型可能学到伪相关；如果只做对齐不做融合，模型无法充分利用跨模态互补信息。

### 4. Diffusion Model 为什么能生成高质量图像？
**解析：**
扩散模型通过前向加噪 + 反向去噪学习数据分布。训练阶段学习每个时间步的噪声预测，推理阶段从高斯噪声逐步还原图像。相比 GAN：
- 优点：训练更稳定，模式崩塌风险低；
- 代价：采样步骤多，推理慢。
工程优化包括 DDIM、DPM-Solver、蒸馏采样和 latent diffusion，用更少步数换取可接受质量。

### 5. 语音识别（ASR）系统评估为什么不能只看 WER？
**解析：**
WER（词错误率）是基础指标，但并不足够：
- 对中文场景还要看 CER（字错误率）；
- 业务场景关注关键词召回率（如命令词、实体词）；
- 实时系统还要考察延迟、稳定性、噪声鲁棒性。
真实系统通常采用离线准确率 + 在线延迟 + 关键业务指标三维评估。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：AdamW 相比 Adam 的核心改进是（ ）
A. 使用动量替代自适应学习率  
B. 将权重衰减与梯度更新解耦  
C. 不再使用一阶矩估计  
D. 只适用于 CNN

**参考答案：** B  
**答案解析：** Adam 中 L2 正则与自适应更新耦合，实际衰减效果会失真；AdamW 将权重衰减作为独立项处理，使正则行为更符合预期，泛化性能通常更稳定。

### 单选题 2：在 Transformer 中，最直接提升长文本建模效率的方向是（ ）
A. 增大词表规模  
B. 将前馈层全部替换为卷积  
C. 降低注意力计算复杂度  
D. 删除位置编码

**参考答案：** C  
**答案解析：** 标准自注意力复杂度为 O(n)，长文本时成本高。稀疏注意力、线性注意力、Flash Attention 的核心都在于降低或优化注意力计算开销。

### 单选题 3：多模态检索中 CLIP 的典型训练目标是（ ）
A. 语言建模损失  
B. 对比学习损失  
C. 回归损失  
D. 强化学习奖励

**参考答案：** B  
**答案解析：** CLIP 通过图文对比学习拉近匹配样本、拉远不匹配样本，形成统一语义空间，便于零样本分类和跨模态检索。

### 单选题 4：扩散模型推理慢的直接原因是（ ）
A. 参数量太小  
B. 需要多步迭代去噪  
C. 只能在 CPU 上运行  
D. 不支持并行计算

**参考答案：** B  
**答案解析：** 采样时需要按时间步逐步去噪，步数越多越慢。优化手段通常是减少步数或改进求解器。

### 简答题 1：请说明你会如何设计一个图文问答多模态系统的训练与评估方案。
**参考答案：**
可从数据、模型、训练、评估、上线五层设计：
1. 数据层：构建图文对齐数据，覆盖常见场景和长尾样本，加入噪声样本做鲁棒性训练。  
2. 模型层：视觉编码器 + 文本编码器 + 跨模态融合模块（如 cross-attention）。  
3. 训练层：先对齐预训练，再指令微调；加入 hard negative 提升区分能力。  
4. 评估层：准确率、召回率、解释一致性、延迟、成本。  
5. 上线层：灰度发布 + 在线监控 + 反馈闭环。

**答案解析：** 这类题重点不在背某个模型名，而在系统化思路。候选人若能同时覆盖算法效果和工程可落地性，通常能拿高分。

### 简答题 2：为什么大模型语音助手常采用ASR + LLM + TTS流水线而不是单模型端到端？
**参考答案：**
- 模块化可替换：每层可独立优化和升级；
- 诊断清晰：错误定位更容易；
- 成本可控：可按场景选择轻量组件；
- 合规更好：文本中间态便于审计与安全过滤。

**答案解析：** 端到端方案理论上简洁，但在工业场景中，模块化流水线往往更易维护、可观测、可灰度，整体交付风险更低。
