# 追问逻辑链 - AI 工程师（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. 什么是高质量追问链？
**解析：**
高质量追问链应从概念题逐步升级到原理题、实战题与权衡题，形成梯度评估，避免一问定生死。

### 2. AI 岗追问为什么要覆盖效果 + 成本 + 风险？
**解析：**
真实项目不只追求精度，还要控制时延、成本和安全风险。追问链应验证候选人的工程完整性认知。

### 3. 如何判断追问深度是否合理？
**解析：**
深度应与候选人层级匹配：应届生看基础与思维，中高阶看落地细节与决策能力。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：AI 追问链从 L1 到 L3 的合理演进是（ ）
A. 概念 -> 原理 -> 实战  
B. 实战 -> 概念 -> 原理  
C. 只问概念  
D. 只问项目名

**参考答案：** A  
**答案解析：** 梯度递进能更准确评估能力上限。

### 单选题 2：评估 RAG 能力时，不应缺失的维度是（ ）
A. 检索质量  
B. 生成可靠性  
C. 安全治理  
D. 以上都要

**参考答案：** D  
**答案解析：** RAG 是系统工程，单点指标不够。

### 简答题 1：请设计一条Transformer 主题的三层追问链。
**参考答案：**
L1 问核心机制；L2 问复杂度与优化；L3 问项目中如何做性能与质量权衡。

**答案解析：** 层级清晰、逐步加压是追问链设计关键。

### 简答题 2：如何在追问中识别背答案与真理解？
**参考答案：**
通过条件变化题、反例题、边界题和场景迁移题，观察候选人是否能稳定迁移原理。

**答案解析：** 真理解具备跨场景一致性，背答案通常在变式题中失效。
