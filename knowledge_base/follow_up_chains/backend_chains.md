# 追问逻辑链 - 后端工程师（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. 后端追问链为什么强调故障场景？
**解析：**
后端系统核心在稳定性。仅会正常路径不够，必须验证候选人在高并发、异常和降级场景下的决策能力。

### 2. 为什么缓存题追问常常落到一致性问题？
**解析：**
缓存的真实难点在并发一致性与失效策略，不在会不会用 Redis 命令。

### 3. 架构题如何分层追问更有效？
**解析：**
可按业务目标 -> 技术方案 -> 风险治理 -> 监控回路分层，逐步增加复杂度。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：高并发系统追问中最容易暴露短板的环节是（ ）
A. 首页 UI  
B. 异常链路与降级策略  
C. 代码行数  
D. IDE 配置

**参考答案：** B  
**答案解析：** 线上稳定性问题通常来自异常路径处理不足。

### 单选题 2：消息队列题的高分追问方向是（ ）
A. 图标样式  
B. 幂等、重试、死信与顺序性治理  
C. 页面文案  
D. 代码格式

**参考答案：** B  
**答案解析：** 这是 MQ 落地的核心治理点。

### 简答题 1：请给出缓存一致性三层追问链。
**参考答案：**
L1 问常见模式；L2 问并发竞态与双删策略；L3 问线上故障案例与补偿机制。

**答案解析：** 层次化追问可有效识别项目真实参与深度。

### 简答题 2：如何追问分布式锁以区分初中高水平？
**参考答案：**
初级看实现，中级看过期和误删风险，高级看时钟漂移、可用性和业务兜底设计。

**答案解析：** 追问维度应覆盖机制、风险和业务影响。
