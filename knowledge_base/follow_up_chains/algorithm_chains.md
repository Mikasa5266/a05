# 追问逻辑链 - 算法工程师（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. 算法追问链为什么要从基础题走向复杂场景题？
**解析：**
基础题验证知识准确性，复杂场景题验证抽象与迁移能力。两者结合才能识别真实能力上限。

### 2. 动态规划追问常见深挖方向有哪些？
**解析：**
状态定义、转移方程、边界条件、空间优化、复杂度证明、错误示例修复，这些是区分会做题和会解释的关键点。

### 3. 算法面如何避免只背模板？
**解析：**
通过变式题和约束变更题追问，观察候选人是否能重建思路，而非机械套模板。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：追问DP 是否可一维优化的核心考察点是（ ）
A. 记忆力  
B. 状态依赖关系理解  
C. 英文能力  
D. 绘图能力

**参考答案：** B  
**答案解析：** 一维优化本质依赖状态转移方向与覆盖关系。

### 单选题 2：二分答案题最关键的前提是（ ）
A. 数据随机  
B. 结果空间单调可判定  
C. 输入有序  
D. 只能递归

**参考答案：** B  
**答案解析：** 无单调性就无法稳定二分边界。

### 简答题 1：请设计一条图算法三层追问链。
**参考答案：**
L1 问算法适用条件；L2 问复杂度与边界；L3 问工程场景落地与选型权衡。

**答案解析：** 优秀追问链应覆盖会不会、懂不懂、能不能用。

### 简答题 2：如何通过追问识别候选人的复杂度分析能力？
**参考答案：**
要求其说明主导操作次数、最坏情况、空间开销，并让其比较两种方案在不同规模下的临界点。

**答案解析：** 复杂度能力是算法岗位核心区分项。
