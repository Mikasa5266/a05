# 前端工程师 - 框架深度（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. Vue3 响应式系统的核心机制是什么？
**解析：**
Vue3 基于 Proxy 进行依赖追踪与触发更新。读取时收集依赖，写入时触发 effect。理解响应式的收集 - 触发链路，有助于解释为什么某些更新不生效或重复触发。

### 2. 虚拟 DOM 的价值是什么？
**解析：**
虚拟 DOM 并非绝对更快，而是提供可预测的跨平台抽象与更新策略。性能收益来自差异化更新、批处理和编译期优化协同，而非单点机制。

### 3. React Hooks 常见误区有哪些？
**解析：**
常见误区是依赖数组不完整、闭包捕获旧值、把副作用放在渲染逻辑中。Hooks 不是函数式语法糖，而是状态与副作用组织方式。

### 4. 状态管理为何要区分服务端状态和客户端状态？
**解析：**
服务端状态有时效性和同步需求，适合 Query 类工具；客户端状态更偏 UI 交互与会话控制。混用会导致缓存失效和逻辑耦合。

### 5. 路由守卫设计如何避免首屏抖动？
**解析：**
应在路由解析前完成最小鉴权判断，延迟加载页面数据，并提供统一 loading/skeleton，避免先渲染后重定向引发闪烁。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：Vue3 响应式追踪核心基于（ ）
A. Object.defineProperty  
B. Proxy  
C. JSON 序列化  
D. LocalStorage

**参考答案：** B  
**答案解析：** Vue3 使用 Proxy 实现更完整的拦截能力。

### 单选题 2：Hooks 中因依赖数组缺失导致的问题通常是（ ）
A. 样式失效  
B. 闭包读到旧状态  
C. DNS 失败  
D. 路由不存在

**参考答案：** B  
**答案解析：** 依赖声明不完整会导致 effect 不按预期更新。

### 单选题 3：服务端状态管理更适合使用（ ）
A. 手写全局变量

C. CSS Modules  
D. SVG 精灵图

**参考答案：** B  
**答案解析：** 服务端状态强调缓存、失效、重取与同步策略。

### 单选题 4：虚拟 DOM 的主要意义更接近（ ）
A. 保证永远最快  
B. 提供跨平台更新抽象和可维护性  
C. 替代所有编译优化  
D. 只用于动画

**参考答案：** B  
**答案解析：** 虚拟 DOM 是工程抽象，不是单一性能银弹。

### 简答题 1：请说明你如何设计一个中大型前端项目的状态分层。
**参考答案：**
- 组件本地状态：临时交互；
- 全局客户端状态：用户会话、主题、权限；
- 服务端状态：接口数据缓存与同步；
- 派生状态：通过 selector/computed 计算，避免冗余存储。

**答案解析：** 高分回答需体现单一数据源 + 职责分离 + 可维护演进。

### 简答题 2：路由权限复杂时，你如何保证可维护性？
**参考答案：**
用统一权限模型定义路由元信息，守卫层只做判定与跳转，业务页面不散落鉴权逻辑；并配套权限测试用例与回归检查。

**答案解析：** 权限治理应集中化，否则迭代后极易出现漏拦截和体验问题。
