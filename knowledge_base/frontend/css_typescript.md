# 前端工程师 - CSS 与 TypeScript（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. BFC 在布局中解决了哪些典型问题？
**解析：**
BFC 可隔离内部和外部布局影响，常用于清除浮动、阻止外边距折叠、限制浮动元素覆盖。理解 BFC 是写稳定布局的基础能力。

### 2. Flex 与 Grid 如何选择？
**解析：**
Flex 适合一维布局（行或列），Grid 适合二维布局（行列同时控制）。工程中常组合使用：外层 Grid 分区，内层 Flex 对齐。

### 3. TypeScript 的类型系统为什么能降低线上风险？
**解析：**
TS 可在编译期发现参数、返回值和状态形状不一致问题，减少运行期崩溃。尤其在多人协作和接口频繁演进时，类型是最稳定的协作契约。

### 4. any、unknown、never 的使用边界是什么？
**解析：**
- any：放弃类型检查，慎用；
- unknown：安全顶层类型，使用前需缩小；
- never：表示不可能发生，常用于穷尽检查。
掌握三者边界能显著提升代码健壮性。

### 5. 响应式布局为什么推荐内容优先而不是设备优先？
**解析：**
设备尺寸不断变化，内容结构更稳定。以内容断点驱动布局，能降低适配碎片化和维护成本。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：下列最可能创建 BFC 的属性组合是（ ）
A. display: inline  
B. overflow: hidden  
C. position: static  
D. float: none

**参考答案：** B  
**答案解析：** 设置 overflow 非 visible 常会触发 BFC。

### 单选题 2：需要同时控制行列关系的页面区域，更适合使用（ ）
A. Flex  
B. Grid  
C. Float  
D. Table

**参考答案：** B  
**答案解析：** Grid 在二维布局表达上更直接。

### 单选题 3：在 TypeScript 中，最安全地承接未知输入应使用（ ）
A. any  
B. unknown  
C. never  
D. void

**参考答案：** B  
**答案解析：** unknown 需要显式缩小后使用，安全性高于 any。

### 单选题 4：用于确保 switch 分支穷尽性的常见类型是（ ）
A. string  
B. unknown  
C. never  
D. symbol

**参考答案：** C  
**答案解析：** never 常用于 default 分支断言，防止遗漏分支。

### 简答题 1：请说明你在 Vue/React 项目里如何落地 TypeScript 规范。
**参考答案：**
- 建立接口类型与领域模型分层；
- 禁止随意 any，开启严格模式；
- 公共组件 props/event 类型化；
- API 响应统一解码与校验；
- 在 CI 中加入类型检查门禁。

**答案解析：** TS 价值在全链路约束，不是只在组件里加几个类型注解。

### 简答题 2：复杂页面布局错位时，你的排查顺序是什么？
**参考答案：**
先看盒模型和尺寸约束，再看定位与层叠上下文，接着看 Flex/Grid 规则冲突，最后看媒体查询和内容溢出。

**答案解析：** 结构化排查能显著降低调样式时间。
