# 算法工程师 - 机器学习基础（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. 偏差与方差为什么是建模核心矛盾？
**解析：**
高偏差代表模型欠拟合，高方差代表模型过拟合。训练过程要在表达能力和泛化能力之间平衡。常见策略包括正则化、特征选择、数据增强和模型复杂度控制。

### 2. 为什么不平衡样本场景不能只看准确率？
**解析：**
当负类占比极高时，即使模型几乎不识别正类，准确率也可能很高。应结合 Precision、Recall、F1、PR-AUC、KS 等指标，才能判断模型是否真正有业务价值。

### 3. 交叉验证在小样本任务中价值在哪里？
**解析：**
小样本下单次划分偶然性很大。K 折交叉验证可重复评估多个切分，得到更稳定的泛化估计，降低运气好坏带来的评估偏差。

### 4. 线上数据漂移会带来什么后果？
**解析：**
当线上输入分布偏离训练分布，模型性能会退化。常见诱因包括用户行为变化、业务策略变化、节假日季节性。需要持续监控特征分布与标签反馈，触发重训练或阈值重标定。

### 5. 为什么树模型通常不强制做标准化？
**解析：**
树模型按分裂阈值比较特征，不依赖距离度量；而线性模型、SVM、KNN 对尺度更敏感。标准化是否必要应看算法机制，而非一刀切。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：类别极不平衡时，更能反映正类识别能力的指标体系是（ ）
A. Accuracy  
B. PR 曲线与 F1  
C. 训练轮次  
D. 参数量

**参考答案：** B  
**答案解析：** PR 曲线和 F1 更关注正类识别效果，适合不平衡场景。

### 单选题 2：L1 正则化相较 L2 的典型特征是（ ）
A. 不会产生稀疏解  
B. 更容易将部分权重压到 0  
C. 只能用于深度学习  
D. 无法用于逻辑回归

**参考答案：** B  
**答案解析：** L1 具备特征选择效果，L2 更偏向平滑收缩。

### 单选题 3：随机森林抑制过拟合的关键机制是（ ）
A. 单棵深树拟合全部样本  
B. Bagging 与特征随机采样  
C. 固定学习率  
D. 去掉验证集

**参考答案：** B  
**答案解析：** 样本与特征随机化降低树之间相关性，集成后泛化更稳定。

### 单选题 4：发现线上输入分布突变，第一步应做的是（ ）
A. 立刻扩大模型规模  
B. 关闭监控系统  
C. 进行漂移诊断并定位来源  
D. 删除全部异常样本

**参考答案：** C  
**答案解析：** 先定位漂移来源，再决定重训、阈值调整或策略修复，避免盲目操作。

### 简答题 1：请给出一个二分类模型的离线评估方案。
**参考答案：**
1. 数据切分：按时间或业务规则防止泄漏；
2. 核心指标：AUC、F1、PR-AUC、KS、校准误差；
3. 分层评估：按人群、渠道、地区、设备切片；
4. 错误分析：关注高置信误判与业务高风险样本；
5. 阈值模拟：结合收益/成本做决策阈值选择。

**答案解析：** 完整评估应连接业务目标。只追求单一指标常导致离线好看、线上无效。

### 简答题 2：模型上线后效果下滑，你的排查顺序是什么？
**参考答案：**
- 先看数据链路：字段缺失、埋点变更、特征计算失败；
- 再看分布变化：输入漂移、标签延迟；
- 再看服务稳定性：超时、降级、缓存失效；
- 最后看策略：阈值与业务目标是否仍匹配。

**答案解析：** 该题重在工程排障方法。结构化排查比凭经验猜原因更容易快速止损。
