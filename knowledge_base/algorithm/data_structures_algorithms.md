# 算法工程师 - 数据结构与算法（知识点 + 题库）

## 一、知识点部分（问题 + 解析）

### 1. 动态规划与贪心的本质区别是什么？
**解析：**
贪心依赖局部最优可推出全局最优的性质，动态规划依赖最优子结构 + 重叠子问题。如果无法证明贪心选择性质，就应优先考虑 DP。面试中高分关键是能说明为什么该题不能贪心。

### 2. 二分查找为何高频出错？
**解析：**
核心在边界不变量定义不清。要先明确维护区间是闭区间还是半开区间，再确定循环条件、中点写法和收缩策略。二分题不是模板背诵题，而是区间语义题。

### 3. 图算法选型的核心判断维度有哪些？
**解析：**
主要看三点：
- 图的类型：有向/无向、稀疏/稠密；
- 权重条件：有无负权、是否要求全源最短路；
- 目标任务：连通性、最短路、拓扑依赖、最小生成树。
算法选型本质是约束匹配，而不是看到图就 DFS。

### 4. 回溯和 DFS 是什么关系？
**解析：**
回溯是 DFS 的应用范式，特点是试探 - 撤销 - 剪枝。DFS 偏遍历，回溯偏解空间搜索。组合、排列、子集、棋盘类题目通常以回溯建模。

### 5. 如何在面试中讲清时间复杂度？
**解析：**
建议按主导操作次数 -> 每次代价 -> 总复杂度表达，再补充最坏和平均情况。只报 O(nlogn) 不解释来源，通常会被追问到失分。

## 二、题库部分（单选题 + 简答题）

### 单选题 1：0-1 背包一维优化时，容量循环方向应为（ ）
A. 从小到大  
B. 从大到小  
C. 任意方向  
D. 先小后大

**参考答案：** B  
**答案解析：** 从大到小可避免同一轮重复使用当前物品；从小到大会破坏 0-1 语义，变成完全背包。

### 单选题 2：判断有向图是否有环，最直接方法是（ ）
A. 快速排序  
B. 拓扑排序  
C. 并查集  
D. 二分查找

**参考答案：** B  
**答案解析：** 若拓扑排序后输出节点数小于总节点数，则图中存在环。

### 单选题 3：当答案满足单调性时，常用技巧是（ ）
A. 线段树  
B. 二分答案  
C. 回文树  
D. 随机化

**参考答案：** B  
**答案解析：** 二分答案将优化问题转为判定问题，通过可行性函数定位最优边界。

### 单选题 4：并查集高效的关键优化组合是（ ）
A. 递归 + 哈希  
B. 路径压缩 + 按秩合并  
C. 前缀和 + 差分  
D. 双指针 + 单调队列

**参考答案：** B  
**答案解析：** 这两项优化可显著降低均摊复杂度，适合海量连通性查询。

### 简答题 1：请设计一个海量日志去重统计方案，并给出复杂度分析。
**参考答案：**
可按资源分级：
1. 内存足够：哈希去重，时间 O(n)，空间 O(n)；
2. 内存不足：哈希分桶落盘，分桶去重后汇总；
3. 允许误差：Bloom Filter 预过滤；
4. 分布式：按 key 分片并行统计。

**答案解析：** 该题考察算法到工程的迁移能力。仅回答哈希表不够，需要说明内存边界与可扩展方案。

### 简答题 2：如何快速判断题目更适合 DP 还是回溯？
**参考答案：**
- 求最优值且有重复子问题，优先 DP；
- 求全部解或路径集合，优先回溯；
- 状态可枚举并可转移，DP 更稳；
- 约束复杂需剪枝，回溯更直观。

**答案解析：** 面试官关注题型识别能力。先选对方法，再谈实现，通常是高级候选人的表现。
